# FROM ZERO — Rise City | إعادة بناء Android 3D (v0.5 قيد الاختبار)

النسخة الحالية **تطوير داخلي** وليس إصدارًا متكاملًا أو مستوى رسوميًا واقعيًا نهائيًا.

## ما تغيّر

- صفحة البداية جديدة بتصميم عريض، زر PLAY وزر ⚙ SETTINGS.
- واجهة داخل اللعب مناسبة للموبايل، مع أزرار RUN وUSE وJUMP، وخريطة صغيرة.
- عصاية الحركة تدعم 8 اتجاهات فعلية + اتجاهات بينهما (360 درجة)؛ يمين الشاشة لتحريك الكاميرا باللمس المتعدد.
- حي ثلاثي الأبعاد بموديلات مستوردة من Kenney، مع تصميم واجهات محلات وواجهات سكنية زجاجية وأرصفة وممرات مشاة وتفاصيل معمارية إضافية ثلاثية الأبعاد.
- شخصية NPC واحدة على الأقل تحتوي موديل بشري بحركات Skeleton أصلية من glTF (CesiumMan) بدل تحريك الشخصيات فقط لأعلى وأسفل.
- تحسينات ألوان السماء وإضاءة الشمس، مع إعدادات لتقليل الظلال على الأجهزة الأضعف.

## البناء والتجربة

1. اكبس `Actions` في GitHub للمستودع.
2. اختر آخر تشغيل ناجح لسير العمل `FROM ZERO | Mobile Visual Rebuild v0.5`.
3. حمّل ملف APK من **Artifacts** داخل الـWorkflow Run بعد نجاح البناء.
4. ثبت APK على هاتف أندرويد وافتح اللعبة بالعرض **Landscape**.
5. جرّب الحركة باليسار والسحب يمينًا والنقر على USE عند الأماكن المخصصة.

للبناء محليًا، شغّل `python3 tools/fetch_models.py` أولًا؛ **الملفات الثنائية للموديلات لا تضاف إلى GitHub**، بل تُجلب خلال CI من مصادر برخص مجانية موثقة في `assets/ATTRIBUTIONS.md`. يحتاج بناء APK إعداد أدوات Android Export في Godot 4.6.

⚠️ الإصدار **ليس بعد لعبة مكتملة بصريًا**، ولا يضمن العرض بنفس الجودة على كل جهاز؛ يلزم اختبار واقعي على الجهاز.
