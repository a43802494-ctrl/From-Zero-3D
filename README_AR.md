# من الصفر — النسخة الداخلية (تحديث البيئة والتحكم)

**لم يتم إعلان نسخة رسمية للجمهور.** هذه نسخة تطوير للتحكم والمظهر العام.

- صفحة رئيسية جديدة فيها زر PLAY وزر ⚙ SETTINGS.
- إعدادات للصوت وحساسية الكاميرا والظلال.
- عصاية تحكم 360 درجة مع اختبار ثمانية اتجاهات.
- مدينة مبنية من نماذج Kenney ثلاثية الأبعاد فعلية؛ مبانٍ ومحلات وسيارات وأشخاص وأشجار وإنارة.
- حركات بسيطة للشخصيات، **ليست** أنيميشن احترافيًا كاملًا بجسم وعظام.
- نظام المهمات والفلوس والحفظ الموجود سابقًا.
- مشروع Godot أصلي لأندرويد وليس WebView.

## طريقة تشغيل الكود

شغّل `python3 tools/fetch_models.py` لجلب أصول CC0 ثم افتح المشروع في Godot 4.6.
أو شغّل GitHub Actions وستُحمّل الأصول تلقائيًا أثناء البناء.

الأصول من Kenney وترخيصها CC0 1.0، والمصدر عبر `Hidencod/tge-assets`.

**مهم:** لم يتم تأكيد أداء الأجهزة الحقيقية بعد؛ لا يجوز وصف هذه النسخة بأنها إطلاق احترافي نهائي.
