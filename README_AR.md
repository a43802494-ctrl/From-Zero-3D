# من الصفر — FROM ZERO: RISE CITY

مشروع لعبة أندرويد أصلية ثلاثية الأبعاد بمنظور الشخص الأول، باستخدام **Godot 4.6.3 وGDScript**، وليس WebView.

## ماذا يوجد في هذا التسليم؟ (مراجعة مصدر داخلي 0.3)
- حي 3D يتم تكوينه بالكامل عبر كود أصلي: مبانٍ بواجهات، محلات، سيارات متحركة، أرصفة، طرق، أشجار، إنارة، أجواء غروب.
- كاميرا منظور الشخص الأول، تصادم، جري، قفز، ومؤثرات مشي.
- نظام وظائف مطور: لوحة عقود بـ3 مستويات، فتح مستويات حسب السمعة، مؤقت تسليم، ومكافأة 30% عند الوصول مبكرًا.
- رادار ثنائي الأبعاد يوضح مواقع المحلات وهدف المهمة واتجاه اللاعب دون كلفة كاميرا 3D إضافية.
- متجر طعام وتجديد الطاقة، وترقية السرعة، وشراء أول مشروع للحصول على دخل دوري داخل اللعبة.
- شاشة بداية حديثة، وواجهة HUD، وإيقاف مؤقت، وتوجيه نحو الأهداف، ونظام حفظ/تحميل.
- أدوات تحكم اللمس للموبايل (عصا تحريك على اليسار، السحب على اليمين لتوجيه الكاميرا، زر التفاعل والجري).
- ملفات صوتية أصلية مضغوطة بصيغة OGG، دون نسخ صوتيات محمية من ألعاب أخرى.
- Workflow لبناء APK في GitHub Actions.

**الحالة:** نسخة مصدر أولية قابلة للبناء والاختبار؛ الجودة النهائية على جهازك لم يتم التحقق منها بعد. لا تعتبر نسخة جاهزة للبيع أو للنشر التجاري قبل الاختبار والتطوير.

## التشغيل على الكمبيوتر
1. نزّل Godot 4.6.3.
2. افتح `project.godot`.
3. انتظر الاستيراد ثم اضغط F6 أو F5.
4. الحركة WASD؛ النظر بالماوس؛ E للتفاعل؛ SHIFT للجري؛ SPACE للقفز؛ ESC للإيقاف.

## بناء APK باستخدام GitHub Actions
1. المستودع الخاص باللعبة هو `a43802494-ctrl/From-Zero-3D`. لا تستخدم أي مستودع خاص بمشروع آخر.
2. ارفع **محتويات مجلد FromZero3D بالكامل** إلى جذر المستودع، بما فيها `.github/workflows/android.yml`.
3. من GitHub افتح `Actions` ثم اختر `FROM ZERO | Android APK - internal build` ثم `Run workflow`.
4. إذا نجحت الخطوات، حمّل `FromZero-RiseCity-Android-APK-internal` من `Artifacts` في صفحة تشغيل الـ Action.
5. فك ZIP الناتج وثبّت الـ APK على هاتف أندرويد ARM64.

> لا يمكن الاستغناء عن `Godot Android export templates`؛ يستخدم GitHub Actions صورة `barichello/godot-ci:4.6.3` المجهزة للبناء. أول تشغيل قد يأخذ وقتًا حسب سرعة GitHub.

## تعليمات اللمس
- تحريك: العصا أسفل اليسار.
- النظر: اسحب إصبعك على الجانب الأيمن (بعيدًا عن الأزرار).
- `USE`: تفاعل مع المحل القريب.
- `RUN`: تشغيل/إيقاف الجري.

## قواعد اللعب
- تبدأ بـ 120 EGP.
- اذهب إلى THE DEPOT وافتح لوحة العقود، اختر مهمة متاحة حسب سمعتك، ثم اتبع المؤشر الذهبي والرادار إلى العميل لتسليمها قبل انتهاء العداد. وإذا تأخرت، تحصل على أصل المكافأة دون البونص.
- يمكنك استعادة الطاقة في CAFE، وزيادة السرعة عبر MARKET، وشراء مشروع من BUSINESS HUB.
- يتم حفظ التقدم عند كل عملية مالية أو عند إنجاز مهام.

## حدود هذا الإصدار
- المباني والأصول مرسومة إجرائيًا، وليست موديلات فائقة الواقعية بمستوى ألعاب الاستوديوهات الكبيرة.
- لا تتضمن اللعبة قصة مكتملة، ذكاء اصطناعي متقدم للمارة، سيارات قابلة للقيادة، ولا خريطة مدينة ضخمة.
- لا تتضمن إعلانات أو شراء داخل التطبيق؛ تتم إضافتها لاحقًا فقط بعد اختبار المتعة والاستقرار.
- يجب اختبار الأداء والتصادم والتحكم على عدة أجهزة أندرويد؛ لم يتم إنتاج APK مثبت الصلاحية ضمن هذه المحادثة.

## مهم جدًا: رفع المشروع من أندرويد باستخدام GitHub المتصل
- لا ترفع ZIP نفسه داخل المستودع بدل الملفات؛ ينبغي أن يكون `project.godot` و`scenes` و`scripts` و`.github` في الجذر مباشرة.
- أنشأت المستودع بالفعل. للحصول على إمكانية رفع الملفات عبر GitHub المتصل، فعّل وصول تطبيق GitHub في ChatGPT إلى مستودع `From-Zero-3D` من صفحة إعدادات GitHub > Applications > Installed GitHub Apps > Configure > Repository access.
- عند نجاح GitHub Actions، نزل الـ Artifact المرفق بـ APK. هذا APK للتجربة فقط وموقّع بتوقيع تطوير، لا يستخدم للنشر التجاري.

## فحوصات الحزمة
- فحص محلي سريع للملفات: `python tests/validate_bundle.py`
- Github Actions ينفذ اختبارات الحسابات في `tests/economy_tests.gd` وفحص المشهد قبل بناء APK.
- لم يُجرَ هنا اختبار Godot فعلي لعدم توافر محرك Godot داخل بيئة التنفيذ المحلية، فلا تُفهم هذه الفحوصات على أنها نجاح APK مؤكَّد.
- سجل التعديلات الكامل في `CHANGELOG_AR.md`.
