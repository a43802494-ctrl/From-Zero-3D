# Licensed GLB game art

Assets are fetched by `python3 tools/fetch_models.py` from the pinned public repository
`Hidencod/tge-assets`, which republishes Kenney's CC0 1.0 city, street, car,
character and vegetation models. The APK build includes the required `.glb` files.

Source: https://github.com/Hidencod/tge-assets
Original creator: https://kenney.nl
License: CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/)

The git repository stores only fetch instructions and game code, not original
binary asset files. Download models before running from the Godot editor.
